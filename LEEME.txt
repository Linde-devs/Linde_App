PASOS PARA SUBIRLO (PowerShell, dentro de la carpeta del repo Linde_App)
------------------------------------------------------------------------
1) Traer lo último de GitHub:
     git switch main
     git pull

2) Descomprimir este zip AL LADO del repo (no dentro), por ejemplo en Descargas\parte_josue.

3) Copiar las carpetas "app" y "gradle" del zip dentro del repo (reemplaza los archivos):
     robocopy $HOME\Downloads\parte_josue\app .\app /E
     robocopy $HOME\Downloads\parte_josue\gradle .\gradle /E

4) Borrar lo que ya no se usa de la plantilla:
     git rm app/src/main/java/josue/com/bo/linde/MainActivity.java
     git rm app/src/main/res/layout/activity_main.xml

5) Revisar: NO deben salir local.properties, build/, .gradle/ ni .idea/
     git status

6) Agregar y hacer el commit (va todo junto porque las piezas dependen entre sí;
   por separado no compilaría):
     git add app/src gradle/libs.versions.toml app/build.gradle.kts
     git commit -m "feat(base): base común, login, predios e inspecciones"

7) Subir:
     git push origin main

8) Avisar en el grupo: «Base lista: git pull».
